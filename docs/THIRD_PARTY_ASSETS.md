# Third-party 3D assets

The premium Create Studio is designed to load Red Umbrella-owned garment GLB/GLTF assets when they are available.

For the current T-shirt prototype, the branch uses the `shirt.glb` model from:

- Project: AvatarParzival/3d
- Source: https://github.com/AvatarParzival/3d
- Model: `Models/shirt.glb`
- License: MIT
- Purpose: temporary production prototype for real-mesh rendering, material colour switching, orbit controls, and decal placement.

The temporary source URL should be replaced with a Red Umbrella-hosted, UV-authored garment model before the configurator is treated as the final production 3D asset pipeline.
